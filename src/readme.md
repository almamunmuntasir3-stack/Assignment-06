# 🏋️‍♂️ FitLog — Workout & Fitness Companion

A dark-themed, responsive web application designed for fitness enthusiasts to browse exercises, structure daily workout plans, and track workout statistics effortlessly.

---

## 📖 Short Description

**FitLog** is a modern, no-nonsense workout library and daily exercise planner. Users can explore a comprehensive collection of exercises complete with detailed equipment guides, duration, and calorie estimations. The app allows users to curate a custom daily plan, save favorite exercises, filter or sort by target metrics, and track completed sets in real time.

---

## 🛠️ Technologies Used

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons & Assets:** Custom SVG / Lucide Icons
- **State Management:** React Context API (`ExerciseContext`)
- **Notifications:** [Sonner](https://sonner.emilkowal.ski/) (Toast Notifications)
- **Deployment:** [Vercel](https://vercel.com/)

---

## ⭐ 5 Key Features

1. **🏋️ Dynamic Daily Plan & Saved List Management**  
   Easily add exercises to your personal daily plan or saved list with a single click. Plan counters and badges update instantly across the navigation bar and stats dashboard.

2. **📊 Live Activity & Calorie Analytics**  
   Real-time calculation of total exercise counts, estimated duration (minutes), and total calories burned based on the active workout list.

3. **🔍 Smart Sorting & Filtering**  
   Sort exercises dynamically by **Duration**, **Calories Burned**, or **Rating** to find the most efficient lifts for your specific fitness goals.

4. **⚡ Complete Workout Tracking & Toast Alerts**  
   Mark completed exercises with a single click ("Mark as Done") or remove them from your active schedule, accompanied by clean toast notification feedback.

5. **📱 Fully Responsive Dark UI & Fast Loading States**  
   Built with a sleek dark theme aesthetic and tailored for all screen sizes (mobile, tablet, and desktop), featuring global loading states and skeleton fallbacks.
